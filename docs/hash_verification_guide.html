哈希算法与文件校验

哈希函数（Hash Function）是一种将任意长度的数据映射为固定长度摘要的单向函数。Hash Tools 支持 7 种主流算法：

算法 输出长度 适用场景
SHA-256 256 bit (64 hex) 通用完整性校验，推荐默认
SHA-512 512 bit (128 hex) 高安全要求场景
SM3 (信创) 256 bit (64 hex) 国家密码标准，政企合规
BLAKE3 256 bit (可扩展) 高性能场景，速度最快
SHA3-256/512 256/512 bit NIST 最新标准

文件校验与存证比对

使用 Hash Tools 进行文件完整性验证并与签署完成证明（Certificate of Completion）比对：

  1. 拖入文件
    将需要验证的文件拖入 Hash Tools 窗口。
  2. 选择算法
    根据存证报告中记录的算法类型选择对应的哈希算法。
  3. 获取计算结果
    工具自动计算文件哈希：
    e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
  4. 粘贴对比
    将存证报告中的 Document Hash 粘贴到 "Compare with" 输入框，系统自动比对。
