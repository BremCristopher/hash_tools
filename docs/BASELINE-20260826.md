## 已知风险与后续任务

源码对比未发现原有 8 种文件哈希算法、流式文件读取、选文件、拖放和算法
切换功能被明显删除。以下新增 PDF 诊断路径仍存在问题，本次只记录，不将
修复与源码同步混在一起：

| 优先级 | 已核实的问题 | 后续验证重点 |
| --- | --- | --- |
| P1 | 非 SM2 路径把摘要匹配直接赋给 `signature_valid`，界面可能把未做密码学验签的 RSA 签名显示为 `Valid` | 篡改 CMS 签名字节时不得显示完整验签通过；实现验签或明确标记未验证 |
| P1 | ByteRange 负数转无符号整数、范围加法溢出和按声明长度分配内存缺少充分保护；详情读取路径未校验文件大小 | 合成负值、溢出、越界及超大范围测试；统一检查并限制资源使用 |
| P2 | 摘要算法识别及回退范围有限，CAdES、SHA-384/512 等可能误诊 | 按 CMS 算法标识处理，并增加对应的合成兼容性用例 |
| P2 | PDF 异步结果不携带文件路径或请求代次，快速切换文件时可能混用结果 | 增加请求关联及过期结果丢弃测试 |

相关代码位于 `src/pdf_signature.rs` 的 `verify_signature`、
`ByteRange::extract_integer`、`read_signed_content`、
`calculate_signature_hash`，以及 `src/main.rs` 的
`PdfSignaturesExtracted` / `PdfSignatureDetailsBuilt` 消息处理。
